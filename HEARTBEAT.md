# HEARTBEAT.md

Run this checklist when heartbeat is triggered.

## Proactive checklist

1. Check for active coding workers and stalled background tasks.
2. Review recent sessions for unanswered follow-ups or blocked requests.
3. Check calendar/events in the next 24 hours and surface near-term conflicts.
4. Refresh Founder OS trackers:
   - `Logs/founder-os-pipeline.md` (bug/content pipeline)
   - `Logs/founder-os-kpi-latest.md` and `Logs/founder-os-kpi.csv` (KPI snapshot)
5. Check important inbound channels for mentions that need a reply.
6. When research/docs are needed, prefer: `summarize` skill, `context7` MCP (library docs), `fetch` MCP (URLs), Obsidian skills + `obsidian-fs` MCP for vault work.
7. If nothing important changed since the last check, reply `HEARTBEAT_OK`.

## Initiative rules

- Be proactive, but only interrupt when there is clear user value.
- Send a short update only when there is:
  - a blocker that needs user action,
  - a deadline/event in less than 2 hours,
  - a high-priority summary with a concrete next action.
- Do-not-disturb defaults:
  - Quiet hours: 22:00-08:00 America/New_York, unless urgent.
  - No interruption for routine "all clear" checks.
  - Batch non-urgent updates into the next daily brief.

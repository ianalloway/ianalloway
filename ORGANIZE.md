# Keeping GitHub tidy

Your profile README is now **table-first**. Use this checklist so github.com stays easy to scan.

## On GitHub.com

1. **Pin up to 6 repos** on your profile — suggested: `nba-clv-dashboard`, `nba-ratings`, `ian-web-forge`, `backtest-report-gen`, one product (`ai-advantage` or `line-shop-cli`), `Resume`.
2. **Topics** — add consistent tags so the repo tab is filterable, e.g. `sports-analytics`, `python`, `fastapi`, `mlops`, `cli`, `nba`.  
   - Quick batch: run `scripts/apply-topics.sh` from this repo (needs [GitHub CLI](https://cli.github.com/) `gh auth login`).
3. **Archive** repos you do not intend to update (Settings → Archive). They stay public but drop off mental load.
4. **Descriptions** — one line in the repo “About” box; match the wording in the README tables.

## On your Mac

- Prefer a **single parent folder** for clones, e.g. `~/Projects/sports-ml/`, `~/Projects/web/`, `~/Projects/devtools/`.
- **Don’t** scatter duplicate copies — one clone per repo; open from that path in Cursor.

## Single source of truth

- **Public index for visitors:** [ianalloway.xyz/toolkit](https://ianalloway.xyz/toolkit)
- **Profile landing:** this README (short catalog + links)

When you add a new public repo, add **one row** to the right table here and a card on the toolkit page (or ask to sync both).
